# Прогнозирование продаж: модели временных рядов

ДЗ 2 по курсу «Прогнозирование временных рядов и обработка сигналов». Продолжение [ДЗ 1](https://github.com/GB911f/timeseries-hw1-online-retail): тот же товар `85099B` (JUMBO BAG RED RETROSPOT) из датасета [Online Retail (UCI)](https://archive.ics.uci.edu/dataset/352/online+retail), продажи в штуках.

Для дневного, недельного и месячного рядов строятся прогнозы шести моделей на горизонтах из задания, считаются метрики, и модели сравниваются между собой.

## Файлы

## Запуск

```bash
pip install -r requirements.txt
jupyter execute sales_forecasting.ipynb
```

При первом запуске скачивается `Online Retail.xlsx` (около 23 МБ) с сайта UCI. Если скачивание идёт слишком медленно, файл можно скачать вручную и положить в `data/raw/`. На macOS для LightGBM нужен OpenMP (`brew install libomp`). Ноутбук выполняется около 3 минут, результаты воспроизводимы (у LightGBM фиксирован seed).

## Как устроен эксперимент

Ряды. Дневной ряд - сетка Вс-Пт, как в ДЗ 1 (по субботам магазин закрыт), один шаг равен одному рабочему дню. Праздники остаются пропусками. Недельный и месячный ряды - суммы дневных продаж, неполные периоды отброшены.

| ряд | период | N | начальное обучение | оцениваемые даты | горизонты |
|---|---|---|---|---|---|
| день | 04.01-08.12.2011 | 291 | 140 (до 15.06) | 91, с 25.08 по 08.12 | 1, 7, 31, 61 |
| неделя | 08.01-03.12.2011 | 48 | 24 (до 18.06) | 17, с 13.08 по 03.12 | 1, 4, 8 |
| месяц | 12.2010-11.2011 | 12 | 6 (до мая) | 5, июль-ноябрь | 1, 2 |

Протокол. Прогноз с расширяющимся окном: в каждой точке T модель заново обучается на наблюдениях до T и прогнозирует на h шагов вперёд. Все горизонты оцениваются на одних и тех же датах, поэтому разница между горизонтами зависит только от того, насколько старые данные видит модель. Вариант каждой модели (тип ETS, порядок ARIMA, лаги VAR) выбирается один раз по начальной обучающей части.

Утечка. Предобработку из ДЗ 1 (заполнение пропусков по соседним неделям, центрированные окна, тренд по всему ряду) здесь не используем, потому что она смотрит в будущее. В ноутбуке есть проверка: если заменить все будущие наблюдения случайными числами, прогнозы не меняются.

Модели:
- наивная и сезонная наивная (тот же день недели неделю назад, только для дневного ряда);
- ETS на log(1 + x), тренд и сезонность выбираются по AICc;
- ARIMA (SARIMA) на log(1 + x), d по тестам ADF и KPSS, остальное по AICc;
- VAR по двум рядам: 85099B и сумма других сумок JUMBO BAG;
- LightGBM: одна модель на панели из 114 товаров, отдельная модель на каждый горизонт, признаки - лаги, средние и день недели.

Метрики: MAE (основная внутри частоты), WAPE и MASE (для сравнения частот), RMSE и смещение. MAPE не используем, потому что в ряду есть нулевые продажи.

## Результаты

Лучшая модель по MASE на каждой частоте и горизонте. Полная таблица в `results/metrics.csv`.

|---|---|---|---|---|---|
| день | 1 | LightGBM | 65,4 | 97,6 | 0,67 |
| день | 7 | LightGBM | 65,8 | 112,0 | 0,59 |
| день | 31 | ETS | 66,1 | 104,8 | 0,63 |
| день | 61 | ETS | 67,0 | 95,0 | 0,71 |
| неделя | 1 | LightGBM | 42,2 | 62,0 | 0,68 |

## Выводы

- День: LightGBM, ETS и ARIMA примерно одинаковы, разница между лучшей и второй моделью не больше 1,6% по MAE и по тесту Диболда-Мариано не значима. Все три точнее наивного прогноза на 30-41% по MAE, и это значимо.
- Неделя: лучшие модели снова близки. Наивную они обгоняют на 28-32% на h = 1 и 4, но на 17 неделях это не значимо.
- Месяц: по пяти точкам модель не выбрать, наивный прогноз не хуже остальных.
- На дневном ряду ошибка почти не растёт с горизонтом (у ETS на 1,5% от h = 1 до h = 61). Предсказуемы только уровень и недельный профиль, а основная ошибка - оптовые заказы, которые не предсказать ни на каком горизонте. Исключение - ARIMA с линейным трендом: на h = 61 тренд весны продолжается вперёд, и WAPE растёт с 66 до 81%. На неделях ошибка растёт сильнее, модели не успевают за осенним ростом.
- Чем крупнее агрегация, тем меньше относительная ошибка: на горизонте около месяца WAPE 66% для дня, 42% для недели и 21% для месяца. Но и точек для обучения и проверки становится намного меньше.
- Модели на log(1 + x) прогнозируют медиану. Для MAE это хорошо, но объём занижается: медиана дневных продаж на 37% ниже среднего.
- VAR не помог: другие сумки JUMBO BAG связаны с целевым товаром в тот же день, а связи с опережением почти нет.
- Основные ограничения: данные только за год (рост перед Рождеством модели видят впервые на тесте), непредсказуемые оптовые заказы и короткие недельный и месячный ряды.
